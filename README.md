# სასერტიფიკატო გამოცდა / Final Certification Project

ეს არის ჩემი სასერტიფიკატო საგამოცდო პროექტი, რომელიც აერთიანებს ვებ-დეველოპმენტის კურსზე დასახულ ყველა ძირითად ამოცანასა და ტექნოლოგიას.
This is my final certification project, combining all the core tasks and technologies covered throughout the web development course.

---

## 🚀 გამოყენებული ტექნოლოგიები / Technologies Used

* **სემანტიკური HTML5 (Semantic HTML5)** — გვერდის სწორი და SEO-ოპტიმიზებული სტრუქტურისთვის.
* **Sass / SCSS** — სტილების მოდულური მართვისთვის, ცვლადებისა და Nesting-ის გამოყენებით.
* **Tailwind CSS** — ადაპტური (Responsive) დიზაინის სწრაფი აწყობისთვის Utility კლასებით.
* **JavaScript (ES6+)** — DOM მანიპულაციისთვის, ასინქრონული კოდის (Promises, Async/Await), შეცდომების მართვისა (`try/catch`) და მასივების კომპლექსური დამუშავებისთვის.
* **Git & GitHub** — ვერსიების კონტროლისა და კოდის ორგანიზებული მართვისთვის.

---

## 📂 პროექტის სტრუქტურა / Project Structure

* `index.html` — მთავარი გვერდი, აწყობილი სემანტიკური თეგებით.
* `style.scss` — Sass-ის ფაილი, სადაც გაწერილია საიტის ძირითადი დიზაინი.
* `tailwind.html` — ცალკე გვერდი, რომელიც დემონსტრირებას უკეთებს Tailwind CSS-ის ადაპტურ (Responsive) შესაძლებლობებს.
* `app.html` & `script.js` — JavaScript-ის დავალებების ბლოკი (ასაკის ვალიდაცია, მონაცემების ფეჩი გარე API-დან და მასივების ლოგიკა).
